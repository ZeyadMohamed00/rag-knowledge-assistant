Supervised learning trains a model on labeled examples so it can predict labels for new data. Data is split into training and test sets so the model is judged on examples it has not seen. Overfitting happens when a model memorizes the training data and performs poorly on new data; regularization and more data reduce it. Precision is the fraction of predicted positives that are correct, and recall is the fraction of real positives that were found. Cross-validation repeats the train and test split several times to give a more stable estimate of performance.
