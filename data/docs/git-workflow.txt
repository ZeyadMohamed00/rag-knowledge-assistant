Git tracks changes to files as a history of commits. A branch is a movable pointer to a line of commits, which lets work on a feature happen without disturbing the main branch. A pull request asks teammates to review a branch before it is merged. Merge combines two branches and keeps both histories, while rebase replays commits on top of another branch to create a linear history. Use git stash to set aside uncommitted changes temporarily. Write short commit messages that explain why the change was made.
