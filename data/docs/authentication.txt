Authentication proves who a user is, while authorization decides what that user may do. Passwords must be stored as salted hashes produced by a slow algorithm such as PBKDF2, bcrypt or argon2, never as plain text. A JSON Web Token, or JWT, is a signed token containing claims such as the user id and an expiry time. The server verifies the signature on each request, so it does not need to look up a session, but a token is hard to revoke before it expires. Always use HTTPS so tokens and passwords are not sent in clear text.
