A relational database stores data in tables with rows and columns. A primary key uniquely identifies each row. A foreign key links a row to a row in another table and keeps relationships consistent. An index speeds up lookups on a column at the cost of slower writes and extra storage. A join combines rows from two tables using a shared key. A transaction groups several statements so they either all succeed or all roll back, which protects data integrity. SQL injection is prevented by using parameterized queries instead of building strings from user input.
