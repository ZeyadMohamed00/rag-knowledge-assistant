Docker packages an application with its dependencies into an image, and a running instance of an image is called a container. A Dockerfile lists the steps to build the image, starting from a base image. Layers are cached, so copying the requirements file and installing dependencies before copying the source code makes rebuilds faster. Docker Compose describes several containers, such as a web service and a database, in a single file. Volumes keep data after a container is removed, and ports are published so the host can reach a service.
