REST APIs expose resources through URLs and use HTTP methods to express intent. GET reads data and should not change anything. POST creates a resource. PUT replaces a resource and PATCH changes part of it. DELETE removes it. Status code 200 means success, 201 means created, 404 means not found, 401 means the caller is not authenticated, and 403 means the caller is known but not allowed. Idempotent methods such as PUT and DELETE give the same result when repeated.
