Python is a high-level, dynamically typed language. Variables do not need type declarations because types are checked at runtime. Lists are ordered, mutable sequences, while tuples are ordered but immutable. Dictionaries map keys to values and offer average constant time lookup. A list comprehension builds a new list in one expression, for example squares of numbers. Python uses indentation to define blocks of code instead of braces. The global interpreter lock, or GIL, allows only one thread to execute Python bytecode at a time, so CPU-bound programs usually use multiprocessing instead of threads.
